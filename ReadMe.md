# JavaScript DOM Review Modules (YouthCode Off-Site)

A focused collection of practical code examples to reinforce Front-End JavaScript interaction with the Document Object Model (DOM). This repository is a final review of core JavaScript topics, emphasizing interactive web development and best practices.

## Project Overview

The project contains four modular learning exercises. Each module includes an HTML and a JavaScript file to promote separation of concerns and modular code organization. Examples reference South African / Western Cape contexts (e.g., loadshedding alerts, taxi fare calculators, SA ID validation) for real-world relevance.

Core topics integrated across modules:

- Functions and logic
- Objects and data structures
- Error handling (try...catch)
- Asynchronous JavaScript (Promises, async/await, fetch)

## Module Structure

| Topic                | Files                                         | Core Focus                                                                 | Key Concepts                                      |
|-----------------------|-----------------------------------------------|----------------------------------------------------------------------------|---------------------------------------------------|
| 1. DOM Fundamentals   | dom_fundamentals.html, dom_fundamentals.js | Selecting elements, manipulating content (innerText / innerHTML), creating/removing nodes | Loops, basic functions                            |
| 2. Dynamic CSS        | css_update.html, css_update.js               | Updating visual appearance via .style and .classList                      | Event listeners, conditional logic, objects      |
| 3. Form Handling      | form_events.html, form_events.js             | Capturing input, preventing default submission, validation                | Events, error handling (try/catch), object usage |
| 4. Mega API Final    | mega_api_final.html, mega_api_final.js     | Fetching external JSON and rendering complex HTML                         | Promises, async/await, fetch(), advanced error handling |

## How to Run

1. Clone or download the repository.
2. Open any module's `.html` file directly in your web browser.
3. Use the browser Developer Console (F12) to inspect logs, errors, and DOM changes — especially useful for form_events and mega_api_final modules.
4. For the API module, ensure your environment allows fetch requests (CORS/local server if needed).

## Learning Goals

- Efficiently navigate and modify the DOM.
- Handle asynchronous operations and external data retrieval.
- Implement robust input validation and error handling.
- Write modular, maintainable, and well-commented JavaScript.
